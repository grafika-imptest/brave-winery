# Brave Winery – návrh e-shopu vinařství

> **Pro kodéra:** [docs/PRO-KODERA.md](docs/PRO-KODERA.md)

Statický front-end prototyp e-shopu vinařství (HTML, CSS, JS bez buildu), obsahově podle https://demo.bravewinery.cz/.

- Živý náhled: https://grafika-imptest.github.io/brave-winery/
- Web = složka `dist/`

```bash
npm start                 # http://127.0.0.1:5370
npm install && npm test   # funkční testy v Edge (playwright-core)
```
